# Enigmatic Legacy Port (Fabric / NeoForge)

An unofficial, free and open-source port of **Enigmatic Legacy** to Fabric and NeoForge.

**Enigmatic Legacy is created and owned by [Aizistral](https://aizistral.com) (Aizistral Studios).**
This project does not own any part of it. All original code, assets and design belong to
the creator. Official mod and source:

- Modrinth: https://modrinth.com/mod/enigmatic-legacy
- CurseForge: https://www.curseforge.com/minecraft/mc-mods/enigmatic-legacy
- Source: https://github.com/Aizistral-Studios/Enigmatic-Legacy

## Status

All four Minecraft versions are ported and pass a full dev-client playtest. No release
yet: nothing will be published before the creator has been asked for permission.
See [PLAN.md](PLAN.md).

| Minecraft | Loaders | Status |
|---|---|---|
| 1.20.1 | Fabric | ported, playtested |
| 1.21.1 | Fabric | ported, playtested |
| 26.3 (latest) | NeoForge, Fabric | ported, playtested |
| 1.21.11 | NeoForge, Fabric | ported, playtested |

**NeoForge on 1.21.1:** use [Enigmatic Legacy Plus](https://modrinth.com/mod/enigmaticlegacy-plus)
by Auviotre, an existing port. This project does not target that version.
